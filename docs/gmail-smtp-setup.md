# Подключение автоответа лидам (Gmail SMTP)

Как только кто-то оставляет email в форме на сайте, ему сразу уходит письмо
с приглашением ответить на 3 вопроса для аудита (текст — в
`src/lib/email.ts`). Без настройки ниже письмо просто не отправляется — лид
всё равно сохраняется (Upstash/Sheets) и передаётся в Mailchimp, форма не
падает.

Письма уходят через обычный Gmail-ящик `aleksfialko15@gmail.com` (SMTP +
App Password) — без своего домена сервисы вроде Resend/SES отправляют
письма только на почту владельца аккаунта, а Gmail шлёт на любой адрес
сразу.

Займёт ~2 минуты.

---

## Шаг 1. Включить двухфакторную аутентификацию

App Password работает только при включённой 2FA.

[myaccount.google.com/security](https://myaccount.google.com/security) →
**Как вы входите в аккаунт Google** → **Двухэтапная аутентификация** →
включить, если ещё не включена.

## Шаг 2. Создать пароль приложения

[myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords)
→ введи любое имя (например «AI Integrator site») → **Создать**.

Google покажет 16-значный код вида `abcd efgh ijkl mnop` — скопируй его
(пробелы можно оставить или убрать, значения не имеет).

## Шаг 3. Добавить переменные в Vercel

```
GMAIL_ADDRESS=aleksfialko15@gmail.com
GMAIL_APP_PASSWORD=<16-значный код из шага 2>
```

Production + Preview, затем передеплой (переменные окружения подхватываются
только на новой сборке).

## Проверка

Оставь email в форме на сайте — письмо должно прийти за несколько секунд.
Если нет — смотри логи функции `/api/subscribe` в Vercel: при не
настроенных переменных там будет `[email] GMAIL_ADDRESS/GMAIL_APP_PASSWORD
не настроены`, при неверном пароле — `[email] Gmail SMTP отправка не
удалась`.

## Лимит

Обычный (не Workspace) Gmail — 500 писем в сутки с одного ящика. Для формы
лендинга с этим объёмом столкнуться нереально.
