# Google Ads: тег отслеживания конверсий

Тег уже вшит в сайт — он рендерится в обоих корневых layout'ах, то есть стоит на
всех страницах: и русских, и английских, и на `/thank-you`. Осталось включить
его переменными окружения и создать конверсионное действие в Google Ads.

Займёт ~10 минут.

---

## Что вообще происходит

Отслеживание конверсий в Google Ads — это две разные вещи, и путаница между ними
самая частая причина «конверсии не считаются»:

| | Что это | Где берётся |
|---|---|---|
| **ID аккаунта** | `AW-18392989021` — твой рекламный аккаунт | один на весь аккаунт |
| **Метка конверсии** | `AbC-D_efGhIjKlM` — конкретное действие («заявка», «покупка») | своя у каждого конверсионного действия |

Тег на странице (`gtag('config', 'AW-...')`) сам по себе **не считает конверсии**.
Он только загружает библиотеку и ставит cookie, по которой Google потом связывает
визит с кликом по объявлению. Конверсия засчитывается отдельным событием:

```js
gtag('event', 'conversion', { send_to: 'AW-18392989021/AbC-D_efGhIjKlM' });
```

Поэтому и переменных окружения две.

> ✅ **Для этого проекта всё уже создано.** Действие-конверсия «Отправка формы
> для потенциальных клиентов» существует, метка — `eqaUCNqZveIcEN36usJE`, оба
> значения проставлены в `.env.example`. Шаг 1 нужен, только если понадобится
> завести ещё одно действие; иначе сразу к шагу 2.

## Шаг 1. Создать конверсионное действие

Google Ads → значок **«Цели»** в левой панели → **Конверсии** → **Сводка** →
кнопка **«+ Создать действие-конверсию»** → **Конверсии на сайте**.

⚠️ Именно **«Сводка»**, а не «Настройки» — на странице настроек кнопки создания
нет, и это самое частое место, где все застревают.

1. Введи домен сайта, нажми **Сканировать**.
2. Выбери **«Добавить действие-конверсию вручную»** (автоматическое определение
   здесь не подходит — событие мы отправляем из кода, и без ручного режима
   Google не выдаст метку).
3. Заполни:
   - **Категория цели** — «Отправка формы для потенциальных клиентов» (Submit lead form)
   - **Название конверсии** — например `Lead — подписка на форме`
   - **Ценность** — если один лид в среднем стоит понятных денег, поставь
     «Использовать одинаковую ценность» и укажи сумму. Иначе «Не использовать»,
     но тогда оптимизировать кампании по ценности не выйдет.
   - **Способ подсчёта** — **Одна (One)**. Для лидов это правильный вариант:
     один посетитель = один лид, даже если он отправил форму трижды.
   - **Окно конверсии** — 30 дней по умолчанию, для короткого цикла сделки этого
     хватает.
4. Сохрани → **Настроить тег** → **Установить тег самостоятельно**.

На этом экране Google покажет готовый сниппет. Тебе нужна из него **одна
строка** — `send_to`:

```js
gtag('event', 'conversion', {'send_to': 'AW-18392989021/AbC-D_efGhIjKlM'});
                                          ^^^^^^^^^^^^^^ ^^^^^^^^^^^^^^^
                                          это ID аккаунта  это метка
```

Часть после слэша — метка. Скопируй её.

## Шаг 2. Прописать переменные

Локально в `.env.local`, на проде — в панели хостинга (Vercel/Railway →
Environment Variables):

```
NEXT_PUBLIC_GOOGLE_ADS_ID=AW-18392989021
NEXT_PUBLIC_GOOGLE_ADS_LEAD_LABEL=eqaUCNqZveIcEN36usJE
```

⚠️ Префикс `NEXT_PUBLIC_` означает, что значение вшивается в JS-бандл **во время
сборки**. После изменения переменных на проде нужен **редеплой** — просто
перезапуска мало. И да, оба значения видны в исходниках страницы: это нормально,
они и так публичные, ничего секретного в них нет.

Поведение при неполной настройке:

| Что задано | Что происходит |
|---|---|
| ничего | тег не подключается вообще |
| только `ID` | тег стоит, собирает аудиторию для ремаркетинга, конверсии не отправляются |
| `ID` + `LEAD_LABEL` | полноценное отслеживание |

## Шаг 3. Проверить, что работает

**Способ 1 — Tag Assistant (самый надёжный).**
Открой [tagassistant.google.com](https://tagassistant.google.com) → **Add
domain** → введи адрес сайта → откроется твой сайт в отдельном окне с записью
событий. Отправь форму. В Tag Assistant должны появиться два события:
`page_view` и `conversion` — у второго в параметрах будет твой `send_to`.

**Способ 2 — консоль браузера.** Открой сайт, в консоли выполни:

```js
dataLayer            // должен быть массив, а не undefined
```

Отправь форму и посмотри вкладку **Network**, фильтр `collect` — уйдёт запрос на
`googleads.g.doubleclick.net` или `google.com/pagead/...` с твоим `send_to` в
параметрах.

**Способ 3 — интерфейс Google Ads.** Цели → Конверсии. Столбец «Статус» у нового
действия сначала будет **«Не подтверждено»**. После первой реальной конверсии
станет **«Записывает данные»**. Это занимает **до 24 часов** — не пугайся сразу.

> Конверсия засчитывается только если пользователь пришёл по клику на объявление.
> Прямой заход на сайт и отправка формы тег зафиксирует, но в отчётах Google Ads
> конверсии не появится — привязывать её не к чему.

## Как это устроено в коде

```
src/lib/gtag.ts               — обёртка над gtag: trackEvent / trackConversion
src/components/GoogleAdsTag.tsx — сам скрипт тега, рендерится в layout
src/lib/layout.tsx            — подключение <GoogleAdsTag /> на все страницы
src/components/EmailForm.tsx  — вызов trackLeadConversion() после успеха формы
```

### Почему ценность конверсии не задана в коде

Сниппет, который генерирует Google, содержит `value` и `currency` — сейчас это
`1.0 CZK`. В коде мы их не передаём намеренно: ценность уже задана в настройках
самого действия-конверсии, и Google подставит её сам. Так сумму можно поменять в
интерфейсе Google Ads за десять секунд, а не через правку кода и редеплой.

Заодно 1 CZK — это значение из мастера настройки, а не реальная стоимость лида.
Как только появится понимание, сколько лид приносит в среднем, поставьте её
(Конверсии → действие → «Ценность»): без этого умные стратегии ставок не смогут
оптимизироваться по деньгам.

### Когда нужен `event_callback`

В сниппете для кнопок Google оборачивает всё в `gtag_report_conversion(url)` с
`event_callback` — чтобы переход по ссылке не оборвал ещё не ушедший запрос. Нам
это не нужно: после отправки формы происходит клиентский переход через
`router.push`, страница не выгружается, и запрос долетает в любом случае.
`event_callback` понадобился бы только для обычной ссылки или `window.location`.

Конверсия отправляется **в момент успешного ответа API**, до редиректа на
`/thank-you`, а не на самой странице благодарности. Причина: на `/thank-you`
можно вернуться кнопкой «назад» или из закладки — и каждый такой заход считался
бы новым лидом. Дополнительно в событие идёт `transaction_id` — по нему Google
отбрасывает дубли.

## Как добавить свою конверсию

Допустим, ты хочешь считать конверсией запуск любого AI-инструмента.

**1.** Создай в Google Ads ещё одно конверсионное действие (Шаг 1), категория —
«Другое». Скопируй его метку.

**2.** Добавь переменную в `.env.local` и на хостинг:

```
NEXT_PUBLIC_GOOGLE_ADS_TOOL_LABEL=XyZ-1_23456789
```

**3.** Вызови в нужном месте:

```tsx
import { trackConversion } from "@/lib/gtag";

const TOOL_LABEL = process.env.NEXT_PUBLIC_GOOGLE_ADS_TOOL_LABEL ?? "";

// ...внутри обработчика, после успешного ответа
trackConversion(TOOL_LABEL, { value: 5, currency: "USD" });
```

`trackConversion` безопасна: если тег не загрузился или метка не задана, она
просто вернёт `false` и ничего не сломает. Отдельно есть `trackEvent(name,
params)` — для обычных событий, не конверсий.

## Частые грабли

**«Конверсий 0, а лиды идут».** Проверь, что трафик действительно из Google Ads.
Конверсия привязывается к клику по объявлению; органика и прямые заходы в отчёте
Ads не появятся.

**«Тега нет на странице».** Забыт редеплой после добавления `NEXT_PUBLIC_`
переменных. Проверь исходный код страницы (Ctrl+U) — там должен быть
`googletagmanager.com/gtag/js?id=AW-...`.

**«Конверсий вдвое больше, чем лидов в таблице».** Значит, событие отправляется
дважды. Убедись, что не добавил вызов ещё и на `/thank-you` — этого делать не
нужно, конверсия уже уходит из формы.

**Блокировщики рекламы.** uBlock/AdGuard режут gtag.js. Часть конверсий (по
разным оценкам 10–30%) теряется — это норма для всех сайтов, не баг. Реальное
число лидов всегда сверяй с Google-таблицей, а не с Google Ads.

**Конверсии от ботов.** Если в форме начнут появляться мусорные адреса, в отчётах
это отразится накруткой. Honeypot-поле в форме отсекает простые боты, но не все.
