# Подключение автоответа лидам (Resend)

Как только кто-то оставляет email в форме на сайте, ему сразу уходит письмо
с приглашением ответить на 3 вопроса для аудита (текст — в
`src/lib/email.ts`). Без настройки ниже письмо просто не отправляется — лид
всё равно сохраняется (Upstash/Sheets) и передаётся в Mailchimp, форма не
падает.

Займёт ~3 минуты.

---

## Шаг 1. Завести аккаунт и ключ

1. Зарегистрируйся на [resend.com](https://resend.com) (есть бесплатный тариф
   — 3000 писем/месяц, 100/день).
2. **API Keys** → **Create API Key** → скопируй значение (начинается с `re_`).

## Шаг 2. Добавить переменную в Vercel

```
RESEND_API_KEY=re_...
```

Production + Preview, затем передеплой (переменные окружения подхватываются
только на новой сборке).

## Шаг 3 (опционально). Свой адрес отправителя

Без домена в Resend письма уходят с `AI Integrator <onboarding@resend.dev>` —
рабочий вариант, ничего дополнительно настраивать не нужно. Ответы всё равно
приходят на настоящий контактный email (`CONTACTS.email` в
`src/lib/content/index.ts`) — он прописан в `reply_to`.

Если позже появится свой домен и его добавят в Resend (**Domains** → **Add
Domain**, несколько DNS-записей) — можно отправлять от него для лучшей
доставляемости:

```
RESEND_FROM_EMAIL=AI Integrator <hello@your-domain.com>
```

## Проверка

Оставь email в форме на сайте — письмо должно прийти за несколько секунд.
Если нет — смотри логи функции `/api/subscribe` в Vercel: при не настроенном
или неверном ключе там будет `[email] RESEND_API_KEY не настроен` или
`[email] Resend error`.
